# Cigarette Butts to Liquid Pesticide — Research Portfolio

A responsive static portfolio website built with HTML, CSS, and JavaScript for a student research project.

## Features
- Responsive layout for desktop and mobile
- Project overview, objectives, methodology, sustainability impact, and results sections
- Mobile navigation menu
- Accessibility-friendly semantic sections
- No frameworks or build tools required

## Run locally
Download or clone this repository, then open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will appear in the Pages settings.

## Personalize it
- Replace `RE:LEAF` with your project or team name.
- Update the contact email in `index.html`.
- Replace the GitHub profile link with your own profile URL.
- Add your real research data, approved methods, references, photos, and adviser details.
- Do not state that the extract is effective or safe unless supported by your research results.

## Research safety note
Cigarette butts can contain nicotine and other toxic residues. This portfolio is for presenting a research concept and is not a recipe or recommendation for preparing or applying homemade pesticide. Any experiments require qualified supervision, risk assessment, and appropriate waste handling.
